# Security Policy

## Supported Versions

Only the latest version of FluentBitwarden is supported with security updates. Older versions are not supported.

| Version | Supported |
| --- | --- |
| Latest | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please report suspected vulnerabilities using GitHub's private vulnerability reporting for this repository.

Do not open public issues for suspected vulnerabilities or publish exploit details before a fix is available.

FluentBitwarden is an active work in progress and should not be treated as production-ready. Security reports are welcome, but fixes are handled on a best-effort basis.
