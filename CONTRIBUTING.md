# Contributing

## Before You Start

- Use issues for bugs, feature requests, and larger changes.
- Small documentation fixes and obvious bug fixes can go straight to a pull request.
- Report security issues through the process in [SECURITY.md](SECURITY.md), not public issues.

## Development

- Requirements are listed in [README.md](README.md).
- Open `FluentBitwarden.slnx` in Visual Studio or a matching Developer PowerShell environment.
- Keep changes consistent with the existing C#, XAML, and C++ style.
- Do not include secrets, personal vault data, local build output, or generated artifacts unless they are required.

## Pull Requests

- Describe what changed and why.
- Link the related issue when there is one.
- Build the solution before submitting.
- Include screenshots or short notes for UI changes when useful.
